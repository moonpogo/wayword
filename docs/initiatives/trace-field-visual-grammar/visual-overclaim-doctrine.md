# Visual Overclaim Doctrine

Initiative: Trace Field Visual Grammar  
Continuation: Visual Overclaim & Inspectability Doctrine Packet  
Scope: Docs-only visual doctrine

## 1) What Visual Overclaim Is

Visual overclaim is when rendering language implies more certainty, diagnosis, or explanatory authority than the evidence supports.

It occurs when form communicates hidden confidence that the system does not have.

## 2) How Visual Systems Accidentally Imply Hidden Certainty

Visual systems overclaim when they:
- compress uncertainty into smooth singular forms
- remove visible evidence seams
- elevate weak correlations into dominant focal marks
- hide noise and contradiction to preserve aesthetic coherence
- use scientific-looking visual grammar without corresponding measurement rigor

## 3) Specific Overclaim Risks

### Density implying truth
- more marks can be read as "more valid" even when they represent noisy recurrence

### Smoothness implying intelligence
- polished continuous shapes can imply reliable model insight where only recurrence aggregation exists

### Complexity implying insight
- layered complexity can be interpreted as depth of understanding rather than layered uncertainty

### Opacity implying depth
- unreadable visual abstraction can imply profound meaning while reducing inspectability

### Heatmaps implying measurement authority
- heat gradients can imply calibrated quantitative certainty not supported by recurrence evidence

### Gradients implying emotional magnitude
- color intensity can be misread as emotional severity or psychological weight

### Clustering implying identity
- visual grouping can be misread as stable personality or trait identity

### Continuity implying narrative
- smooth temporal continuity can imply causal story arcs not established by evidence

## 4) Rules For Ambiguity Preservation

- never render recurrence as identity
- allow unresolved/contradictory patterns to remain unresolved
- preserve uncertainty as first-class visual state
- avoid singular “master shape” outputs that collapse plural evidence
- keep room for user interpretation without forced explanatory framing

## 5) Rules For Evidence-First Rendering

- every salient visual mark must map to inspectable source traces
- visual prominence must correspond to explicit recurrence evidence thresholds
- uncertain or low-support recurrence must be visually qualified or suppressed
- rendering grammar must make evidence lineage recoverable

## 6) Rules For Sparse/Quiet States

- sparse data should render as sparse, not “filled in” decoratively
- do not fabricate continuity when recurrence is weak
- low-activity states should remain visually quiet
- quiet states are meaningful and should not be treated as design failure

## 7) Rules For Absence/Silence Rendering

- silence/absence must be representable without stigma or deficit framing
- absence should not be color-coded as pathology
- missing recurrence should not be converted into behavioral judgment
- gaps remain observational, not diagnostic

## 8) Explicitly Prohibited Visual Metaphors

- personality-map aesthetics
- sentiment-cloud aesthetics
- pseudo-neuroscience aesthetics
- cosmic or mystical symbolism
- fake scientific instrumentation
- behavioral scoring visual language
- therapy progress metaphors
- dashboard KPI metaphors

## 9) Allowed Visual Tendencies

- restrained field-like distributions
- evidence-linked discrete marks
- modest contrast and low-drama emphasis
- visible uncertainty states
- legible pathways from mark to trace
- clear distinction between observed recurrence and unresolved/noisy signals

## 10) QA Red Flags

Treat as immediate red flags:
- visuals read as emotional scoring at a glance
- visual polish suggests certainty beyond evidence
- narrative inevitability implied by continuity styling
- dense decorative overlays reduce inspectability
- clusters interpreted as identity labels
- silence rendered as deficiency signal

## 11) Founder Decision Targets

- approve anti-overclaim rule set as binding visual doctrine baseline
- approve prohibited metaphor list as hard no-go set
- approve ambiguity and silence handling as non-optional requirements
- approve evidence-first rendering precedence over aesthetic cohesion

## Doctrine Boundaries

This doctrine explicitly rejects:
- GitHub heatmap aesthetics
- productivity dashboard language
- therapy visual framing
- "AI understands you" visual implications
- emotional scoring visual semantics
- certainty theater
- mystical abstraction without evidence
- faux scientific overprecision
- decorative generative slop
