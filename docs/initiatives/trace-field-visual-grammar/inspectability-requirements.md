# Inspectability Requirements

Initiative: Trace Field Visual Grammar  
Continuation: Visual Overclaim & Inspectability Doctrine Packet  
Scope: Docs-only inspectability and evidence linkage requirements

## 1) Evidence Traceability Principles

- every meaningful rendered element must map to evidence traces
- trace mapping must be deterministic for same source + config
- no black-box aggregate may appear without inspectable lineage

## 2) Rendered Form To Source Evidence Relationship

For any rendered form:
- define recurrence primitive(s) represented
- define threshold/filter context used
- define source run/entry references supporting the form
- define whether form includes unresolved or partial evidence

## 3) User Movement: Visualization -> Source Traces

Inspectability posture requires reversible movement:
- from overview form to specific recurrence traces
- from trace to source excerpts/spans
- from source excerpt back to recurrence context

No one-way narrative visualization paths.

## 4) Rules For Surfacing Uncertainty

- uncertainty must be visible, not hidden behind aesthetic smoothing
- low-support recurrence must be clearly differentiated from high-support recurrence
- uncertainty styling must not be mistaken for failure or deficiency

## 5) Rules For Partial Evidence

- partial evidence must remain explicitly partial
- partial matches may not inherit full-confidence visual weight
- visually mark incomplete support without dramatizing it

## 6) Rules For Contradictory Recurrence

- contradictory recurrence may coexist; do not force unification
- visual grammar must support multiple simultaneous weak signals
- contradiction is a valid observational outcome

## 7) Rules For Unresolved/Noisy Recurrence

- unresolved recurrence should be shown as unresolved or suppressed per threshold policy
- noise should not be converted into decorative complexity
- no style choices may imply latent hidden certainty in noisy states

## 8) Rules For Visual Restraint

- prioritize legibility and evidence linkage over decorative novelty
- avoid intensity scaling that implies emotional magnitude
- avoid pseudo-scientific precision cues not backed by actual measurement rigor

## 9) Anti-Black-Box Requirements

- no rendering mode may be accepted if evidence path cannot be explained
- no symbolic layer may bypass evidence lineage checks
- no final form may imply omniscience or psychological diagnosis

Observatory target feeling:
- inspectable
- revisitable
- evidentiary
- incomplete
- observational

Must not feel:
- omniscient
- psychologically diagnostic
- narratively authoritative

## 10) QA Verification Requirements

QA must verify:
- evidence-path completeness for high-salience marks
- uncertainty visibility in low-support cases
- contradiction handling without forced synthesis
- silence/absence handling without deficit coding
- absence of overclaim red-flag metaphors

Automatic fail conditions:
- evidence lineage missing for salient marks
- recurrence rendered as identity inference
- uncertainty hidden by smoothing/density
- visual language implies behavioral scoring

## 11) Conductor Anti-Drift Checks

Conductor checks for each continuation:
- inspectability still dominates over aesthetic theater
- new doctrine text adds decision value, not repetitive restatement
- visual metaphors remain evidence-aligned and non-mystical
- continuation output remains bounded and founder-decision-oriented

Conductor may pause initiative if:
- decorative abstraction overtakes evidentiary clarity
- outputs become recursive doctrine repetition
- initiative drifts toward implementation discussion
