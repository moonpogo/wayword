# Visual Share Surface Review

Date: 2026-05-26

## Purpose

Evaluate which product surfaces translate cleanly into social fragments.

## Share-Worthy Surfaces

- Landing statement block
- Prompt card in active writing state
- Reflection line + post-run panel
- Pattern-formation visual (trace dots)
- Current Season wheel with visible sparse-to-emergent traces

## Caption Pairing Guidance

- Use observational field-note captions, not claims.
- Keep one thesis per post: return, recurrence, or restraint.
- Avoid "feature tour" language.

## Mode Guidance

- Light mode: default for first-touch explanatory posts.
- Dark mode: use for atmospheric/reflective artifact posts.
- Maintain consistency within a thread to avoid visual jitter.

## Share Surface Verdict

Wayword currently has enough coherent surfaces for founder-led screenshot distribution without additional feature work.
