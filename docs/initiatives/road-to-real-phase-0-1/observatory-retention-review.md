# Observatory Retention Review

Date: 2026-05-26

## Objective

Increase revisit tension around Current Season + cross-run emergence without analytics/dashboard feel.

## Sparse-State Issues

- Empty states previously risked reading as "nothing happened."
- "Enough traces" wording could feel binary and slightly clinical.

## Changes Applied

- Observatory empty language now emphasizes gathering and emergence.
- Pattern-formation card now uses gentler progression framing:
  - "beginning to form"
  - "traces saved"
  - "stable patterns emerge"
- Seasonal quiet lines now signal continuity in-progress, not absence.

## Retention Loop Quality (Expected)

- Better curiosity bridge from first runs to observatory revisit.
- Lower emotional drop after sparse observatory states.
- Clearer expectation that meaning sharpens with return, not one-shot analysis.

## Risks Remaining

- If first 3 runs are all very short, observatory may still feel too abstract.
- Some users may still expect explicit "next step" guidance after observatory view.
