# Onboarding Friction Review

Date: 2026-05-26

## Main Friction Points

- "See what you're doing" phrasing can read as evaluative instead of reflective.
- First submit can feel under-rewarding if low-signal language is too blunt.
- Users may not yet understand that value compounds over multiple runs.

## Changes Applied

- Landing value copy now emphasizes recognizable return over judgment.
- Mechanics copy now sets expectation that traces gather progressively.
- Post-submit low-signal line now invites continuation without diagnostic tone.
- Privacy line tightened to preserve emotional safety framing.

## Remaining Watchpoints

- Verify that first run feels meaningful but restrained, not empty.
- Verify that users can explain Wayword in one sentence after onboarding.
- Verify that calibration language never implies scoring or performance assessment.

## Interview Prompts For Alpha

- "What did you think Wayword was trying to help you notice?"
- "After your first run, did you feel invited to continue or finished?"
- "Did any language feel like judgment?"
