# Screenshot Readiness Review

Date: 2026-05-26

## Acquisition Context

Screenshots are a primary top-of-funnel surface for founder-led alpha recruitment.

## Readiness Assessment

- Composition quality: medium-high
- Prompt readability: high in uncluttered states
- Observatory readability: medium (best after 3-5 runs)
- Light mode: strong
- Dark mode: strong but requires careful contrast selection in captured states

## Best Capture States

1. Landing + value language + Begin control
2. Mid-run prompt + active writing field (clean control posture)
3. Post-submit reflection with restrained line
4. Patterns sparse formation card (early tension)
5. Current Season panel with visible but not overloaded traces

## Weak Capture States

- Very low-signal post-submit with minimal text context
- Observatory no-strong-pattern state without recruitment caption

## Capture Rules

- Prefer states with one clear idea per frame.
- Pair sparse observatory screenshots with explicit founder caption context.
- Avoid captures that make Patterns read like analytics or scoring.
