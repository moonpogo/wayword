# Observatory Sharing Ideas

Date: 2026-05-26

## Goal

Share observatory fragments that communicate recurrence and continuity quickly without dashboard framing.

## Post Ideas

1. "A season is beginning to take shape" + sparse wheel screenshot
2. "Three traces saved, first pattern still forming" + formation card screenshot
3. "No stable pattern yet" + humility caption about weak signal
4. "The return mattered more than the run" + revisit screenshot
5. "Quiet evidence of return" + dark mode seasonal fragment
6. "Still gathering" + side-by-side run 1 vs run 5 observatory

## Caption Prompts

- "What line kept returning for you this week?"
- "Did this feel like recognition or just data?"
- "At what run did it start feeling like yours?"

## Format Suggestions

- single image + 1-2 lines
- carousel: early sparse -> later emergent
- occasional annotated crop highlighting one trace only

## Guardrails

- avoid numerical performance framing
- avoid streak language
- avoid "insight guaranteed" claims
