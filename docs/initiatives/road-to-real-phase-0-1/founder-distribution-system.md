# Founder Distribution System

Date: 2026-05-26
Target: recruit and retain first 20-40 emotionally aligned alpha users

## Operating Thesis

Distribution should mirror the product: specific, restrained, recurrence-oriented, and anti-performance.

## Audience Priorities

- Writers
- Artists
- Reflective technologists
- Journalers
- Aesthetically sensitive users
- People dissatisfied with productivity software

## Channel Roles

- BlueSky: daily field notes + screenshot fragments
- Substack: weekly depth + onboarding framing
- Pinterest: visual artifact streams (prompt/observatory fragments)

## Funnel Shape (Simple)

1. Field note post (problem + stance)
2. Product fragment screenshot (proof)
3. Invite to alpha (small cohort language)
4. 5-run onboarding request
5. 7-day follow-up reflection prompt

## Recruitment Offer Template

"I’m inviting a small alpha cohort into Wayword, a reflective writing instrument. It’s for people who want to notice what returns in their writing over time, not optimize output."

## Weekly Rhythm

- Monday: observational note + screenshot
- Tuesday: artifact-only post
- Wednesday: recruitment invite
- Thursday: process/devlog fragment
- Friday: observatory fragment + reflection question
- Weekend: one quieter repost/highlight or rest

## Retention Follow-Up Protocol

- Day 0: welcome note + expectation of 3-5 runs
- Day 2: check-in question focused on first recurrence signal
- Day 7: observatory revisit prompt
- Day 14: optional reflection survey

## Guardrails

- No growth-hack language
- No optimization framing
- No dashboard metaphors
- No overclaiming sparse signals
