# Global Wayword Doctrine

Wayword is:
- observational
- restrained
- perceptual
- longitudinal
- non-extractive

Wayword is NOT:
- therapy
- productivity software
- quantified self optimization
- AI companionship
- mood diagnosis
- engagement maximization

Core principles:
- observation over diagnosis
- perception before interpretation
- reveal forces, not objects
- build fields, not dashboards
- let time appear as seasons
- data must earn poetry
- cultivate bearing, not productivity
- elegance as understanding
- preserve ambiguity
- avoid overclaiming
